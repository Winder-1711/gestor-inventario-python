# 📦 Sistema de Gestión de Inventario (CLI)

Una aplicación de consola interactiva desarrollada en Python para gestionar productos, precios y existencias en tiempo real.

## 🚀 Funcionalidades
- **Ver catálogo:** Consulta de todos los artículos con formato de moneda y stock.
- **Registro dinámico:** Alta de productos mediante diccionarios en memoria.
- **Búsqueda inteligente:** Localización de artículos sin distinción entre mayúsculas y minúsculas (`case-insensitive`).
- **Navegación interactiva:** Menú continuo controlado por bucle y validación de opciones.

## 🛠️ Tecnologías utilizadas
- Python 3
- Estructuras de datos: Listas y Diccionarios (`List of Dicts`)
- Control de flujo: `while True`, `if / elif / else`
- Formateo de texto avanzado: F-strings con precisión decimal (`:.2f`)

## 💻 Cómo ejecutarlo
1. Clona o descarga este repositorio.
2. Abre la terminal en la carpeta del proyecto.
3. Ejecuta:
   ```bash
   python gestor_inventario.py
   ```
